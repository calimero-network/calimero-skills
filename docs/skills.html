All Skills

Complete reference for every skill file in this repository

Available Skills

Each skill is a plain text file. Running npx calimero-skills <skill-name> appends it to the correct file for your editor:

calimero-core
How core 1.0 works: app instances on their own Raft logs, the system group, organizations and access, accounts and passkeys, attestation and the sealed channel.
calimero-rust-sdk
Rust apps on core 1.0's component SDK: #[app::state]/#[app::logic], tables and collections, env and guards, events, testing, meroctl app build.
calimero-sdk-js
The 0.x JS app SDK (@State/@Logic) is gone: what replaces it (Rust apps, mero-js clients).
calimero-client-js
Frontends and Node.js services on mero-js's CalimeroClient: attested connections, passkeys, app calls and views, organizations, events.
calimero-client-py
Python client for core 1.0: attested Client, API keys and passkeys, calls, events, organizations and the Ops API.
calimero-desktop
Desktop hash-token SSO is 0.x only; a core 1.0 frontend signs in with passkeys through mero-js.
calimero-node
Operating a cluster with meroctl ops: nodes, placement, backups and recovery, quotas, release approvals, upgrades.
calimero-merod
The merod binary: init, config, run and every node flag, local, inspect, kms disk-key, attest, job nodes.
calimero-meroctl
Core 1.0's meroctl: the development cluster (local), sign-in and trust flags, apps, contexts, call --view, organizations and teams, blobs and files, cloud, scripting and CI.
calimero-registry
Publishing apps to the Calimero App Registry with meroctl app — signer new key management, pack (Ed25519 manifest signing), inspect and publish.
calimero-abi-codegen
Typed app clients with meroctl app codegen: what client.ts exports, the component ABI, breaking-change checks.

Install All Skills at Once

# Install every skill for Claude Code + Cursor + Copilot
npx @calimero-network/agent-skills all

# Install specific skills
npx @calimero-network/agent-skills calimero-node calimero-rust-sdk calimero-client-js

Where Skills Are Written

Claude Code
Appended to CLAUDE.md in your project root (or created if absent).
Cursor
Appended to .cursorrules in your project root.
GitHub Copilot
Appended to .github/copilot-instructions.md.

Run from your project root. Skills are additive — running the same skill twice does not duplicate content.
