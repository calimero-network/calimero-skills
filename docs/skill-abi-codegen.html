ABI Codegen Skill

Context for generating a typed client for a Calimero 1.0 app from its ABI with core's mero-app-build codegen

What This Skill Covers

The calimero-abi-codegen skill teaches your AI assistant to generate and use the typed client core writes from the ABI embedded in an app's component. The npm abi-codegen package read SDK 0.12 ABIs only and is not used with core 1.0.

Covered Topics

  • mero-app-build codegen --abi <app.wasm | .mpk | abi.json> --lang ts
  • What client.ts exports: <Name>Client, <Name>Api, raw, events, InitArgs
  • The component ABI (calimero:abi section)
  • Installing mero-app-build in CI
  • abi-diff for breaking changes

Install

npx @calimero-network/agent-skills calimero-abi-codegen

# Recommended with the Rust SDK and the JS client:
npx @calimero-network/agent-skills calimero-rust-sdk
npx @calimero-network/agent-skills calimero-client-js

CLI Usage

# Build the component, then generate openapi.json + client.ts
mero-app-build . --out kv-store.wasm
mero-app-build codegen --abi kv-store.wasm --lang ts -o src/generated

# From an ABI file, naming the client, without the OpenAPI document
mero-app-build codegen --abi res/abi.json --lang ts --name kv-store --no-openapi -o src/api/kv-store

# Breaking changes against the last release
mero-app-build abi-diff dist/kv-store-1.0.0.mpk kv-store.wasm

Generated Output

<Name>Client
new KvStoreClient(client, appId, { after }) over mero-js's CalimeroClient: one method per app method, each taking one args object and an options object.
<Name>Api
The methods alone, for code and tests that take a double.
raw / events
raw answers { result, index, events }; events() yields the app's typed AppEvent union.
Types
<Method>Args, InitArgs, error and event types, and every Record/AbiType type in the ABI.

Key Rules

Regenerate, never edit
Fix the Rust, rebuild the component, regenerate the client.
Derive exchanged types
Every type a method exchanges derives Record or AbiType; otherwise the client types it unknown.
