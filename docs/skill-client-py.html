Python Client Skill

Scripts, services and operator automation on Calimero 1.0 with calimero-client-py

What This Skill Covers

The calimero-client-py skill gives your AI assistant the Python client for core 1.0, checked against the published package: a synchronous Client that attests the node, seals every request, signs in with a passkey or an API key, calls and views app methods, follows events, and drives organizations and the Ops API. The 0.x client (create_connection, contexts, cached tokens) is gone.

Covered Topics

  • Client and Client.connect with a trust policy
  • API keys, SoftPasskey, step-ups (412 CONFIRM_REQUIRED)
  • client.apps.call / view, client.events
  • Organizations, instances, API keys, the operator (client.ops)

Install

npx @calimero-network/agent-skills calimero-client-py

# With typed clients:
npx @calimero-network/agent-skills calimero-client-py calimero-abi-codegen

Connect and Call

pip install calimero-client-py

from calimero_client_py import Client
client = Client.connect("eu-shared-1", tee_profiles=["<profile>"])
client.use_api_key("cal_...")
client.apps.call(app=app_id, method="set", args={"key": "a", "value": "1"})
client.apps.view(app=app_id, method="get", args={"key": "a"}).to_dict()["result"]

Key Rules

No v1 client
create_connection, create_client, contexts and ~/.merobox token caches are gone: use Client.
Trust policy
Name the image profiles you trust (tee_profiles); allow_mock=True only on development clusters.
Synchronous
Every method blocks and returns a value; there is no await.
