JS SDK Skill

The 0.x JavaScript app SDK is gone in Calimero 1.0: what replaces it

What This Skill Covers

Core 1.0 ships no JavaScript app SDK. @calimero-network/calimero-sdk-js and calimero-sdk build produce WebAssembly core modules for the 0.x runtime, which a core 1.0 node refuses (400 UNSUPPORTED_BUNDLE). The calimero-sdk-js skill tells your AI assistant so, and maps each 0.x concept to Rust for apps and mero-js for clients.

Covered Topics

  • Why @State/@Logic code cannot run on core 1.0
  • What the engine's componentize-js compatibility does (and does not) mean
  • A concept map from the 0.x JS SDK to calimero-sdk (Rust)
  • Calling the app from TypeScript with mero-js

Install

npx @calimero-network/agent-skills calimero-sdk-js

# What to install instead:
npx @calimero-network/agent-skills calimero-rust-sdk calimero-client-js

Instead

# the app: Rust, built into a calimero:app component
meroctl app new my-app && cd my-app
meroctl app build apps/kv-store/logic --out app.wasm
meroctl local dev apps/kv-store

# the frontend: TypeScript on mero-js, with a typed client
pnpm add @calimero-network/mero-js
meroctl app codegen --abi logic/res/abi.json --lang ts -o app/src/generated
