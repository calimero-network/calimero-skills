Desktop Skill

Calimero Desktop's hash-token SSO is 0.x only; a core 1.0 app signs people in with passkeys

What This Skill Covers

Calimero Desktop (the Tauri app) still bundles merod 0.12.0 and is built on mero-js 26: its single sign-on hands the 0.x node's JWTs to an app in the URL hash. Core 1.0 nodes issue no such tokens, and mero-js 27 removed parseAuthCallback. The calimero-desktop skill tells your AI assistant what that code belongs to and what a core 1.0 frontend does instead.

Covered Topics

  • What the desktop is and sends today, checked in its source
  • Why access_token in window.location.hash does not apply to core 1.0
  • Passkey sign-in through mero-js CalimeroClient
  • Frontends served from the package, registered origins, API keys

Install

npx @calimero-network/agent-skills calimero-desktop

# For a core 1.0 frontend:
npx @calimero-network/agent-skills calimero-client-js

Sign In on Core 1.0

import { CalimeroClient, browserPasskey } from '@calimero-network/mero-js';

const client = await CalimeroClient.connect({
cluster: 'eu-shared-1',
policy: { release: { minReleaseVersion: '2.3.109' } },
});
await client.signIn(browserPasskey());
