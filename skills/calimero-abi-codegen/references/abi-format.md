# The component ABI

Every core 1.0 app carries an ABI: a JSON description of its surface, generated by `#[app::logic]`
at compile time and embedded in the component as the custom section `calimero:abi`. It is part of
the component's bytes, so it is covered by the bundle's hash and cannot drift from the code.

```json
{
  "abiVersion": 1,
  "world": "calimero:app@0.5.1",
  "state": {
    "fields": { "bookings": "table", "titles": "unorderedMap", "nextId": "counter" },
    "version": 3
  },
  "methods": {
    "book": {
      "kind": "call",
      "params": [
        ["roomId", "string"],
        ["start", "u64"],
        ["title", "string"]
      ],
      "returns": "string",
      "confirm": false,
      "public": false,
      "allowSystem": false
    },
    "roomCount": {
      "kind": "view",
      "params": [["roomId", "string"]],
      "returns": "u64",
      "confirm": false,
      "public": true,
      "allowSystem": false
    }
  },
  "errors": { "NotFound": {}, "Taken": { "start": "u64" } },
  "events": { "Booked": { "id": "string", "roomId": "string", "start": "u64" } },
  "types": {
    "Booking": {
      "kind": "record",
      "fields": [
        ["id", "string"],
        ["roomId", "string"],
        ["start", "u64"]
      ]
    }
  }
}
```

- **`methods`** by camelCase name. `kind` is `init`, `call`, `view`, `timer` or `action`; `params`
  are ordered `[name, type]` pairs; the flags come from the method attributes (`confirm`, `public`,
  `allowSystem`, `every`, `allowApps`).
- **`state`**: each field's collection kind and the `#[app::state(version = N)]`.
- **`errors`** and **`events`**: each code or name with its fields.
- **`types`**: the JSON shape of every `#[derive(Record)]` and `#[derive(AbiType)]` type the
  methods, errors and events name. A type it does not list is unknown to clients.
- **Type names**: Rust integer, float and bool names, `string`, `bytes`, `option<T>`, `list<T>`,
  `tuple<..>`, `unit`, else the Rust type's name. `u64`, `i64` and `bytes` are strings on the wire.

There is no `schema_version: "wasm-abi/1"`, no methods array and no hand-written manifest: the SDK
0.12 format is gone.

## Reading it

- `mero-app-build codegen --abi <app.wasm | bundle.mpk | abi.json>` reads it directly.
- `GET /apps/{app}/abi` returns an installed app's ABI; `meroctl context abi` prints it.
- `GET /apps/{app}/openapi.json` returns it as an OpenAPI 3.1 document, as does
  `mero-app-build codegen --lang openapi`.
